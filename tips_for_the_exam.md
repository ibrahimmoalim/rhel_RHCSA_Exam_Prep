The 2 nodes that you'll be doing tasks on in the exam are not accessible right away with a simple ssh in the terminal, use the vm console as shown in this [RedHat Video](https://youtu.be/Me6Y12-sux8) to access the nodes directly (ignore the part where in the video they show you can access the nodes via terminal, it doesn't work because root login isn't enabled in the nodes, do not mess with the sshd config, just follow this method), you should then make a simple test user (make sure user has same password as the password shown in the exam instructions, any user you create should have this password unless exam asks otherwise) and add that user to the `wheel` group, you should also configure networking and make sure hostname is same as mentioned in the exam instructions,also check that sshd is enabled and running, you should be able to now ssh into that node from the terminal using the test user and ip-addr or hostname, once you're in, do: `sudo su -` to gain root access.
